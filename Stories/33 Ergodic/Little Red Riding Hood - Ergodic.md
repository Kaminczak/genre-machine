# Little Red Riding Hood - Ergodic

**Logline:** Grandmother's cottage has more rooms inside than outside. The path is a footnote, the footnote is hungry, and the hood is Exhibit R.

## Script

Exhibit R. Recovered from the cottage, which measures four rooms outside and six inside; see appendix; the appendix measures eight. The path is documented only in footnote four, which reads: there is no path, there is a direction the trees agree on. The basket inventory runs to two pages — cakes, wine, a knife nobody packed — and each item is annotated in a child's hand, then a woman's hand, then a child's hand again, dated later. Margin note, blue ink: the hood is not red, it is redacted. Margin note, red ink: we are the marginalia. The transcript of the famous dialogue survives with the nouns blacked out: what big [ ] you have. The better to [ ] you with. Page nine is a floor plan of the bedroom; the wardrobe on the plan opens into a second floor plan, drawn smaller, in which the wardrobe stands open. The grandmother appears nowhere in the file, which the final examiner, hand unsteady, reads as proof she escaped it. The file is hungry. Initial here. You have been initialing here, the file notes, for some time.
