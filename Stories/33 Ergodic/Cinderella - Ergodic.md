# Cinderella - Ergodic

**Logline:** The ball's guest list, read in order, spells a name. The slipper's footnote reads SIZE REDACTED. Midnight appears twice in the appendix.

## Script

("Exhibit C. Recovered from the palace archive; filed under lost property; the file disputes the filing. Contents: one guest list for the Autumn Ball, 340 names, of which 339 are annotated attended. The 340th name is written in a hand the archive's graphologist identifies, in an appendix she later asked to have withdrawn, as the reader's own. Contents, continued: one dance card, blank, that fills itself in as the file is read — the archivist's minutes note that by page six the card recorded a waltz between subject and crown prince, though no one had turned to page six yet. Marginalia, various inks: the pumpkin is a calendar. the mice are hours. check the arithmetic of the carriage. The arithmetic, when checked (appendix B), resolves: four mice, two rats, six footmen, one driver — thirteen; the working was always going to fail at twelve. Contents, continued: one slipper, glass, which the file describes as size six and the reader will find, on inspecting the accompanying plate, to be exactly the size of the space between two lines of type. Do not set your finger there. Note 12, in the withdrawing graphologist's hand: the stepmother's testimony is bound into the file upside down; inverted, it reads as a confession; the file will not permit it to be photographed right-side up. Note 13, unsigned: midnight in this document occurs twice — page four and page eleven — and the text between them is the ball, which means the reader is currently inside it, which means the dance card in your hands is filling in, which means. Note 13 ends there. Final page: the fit. The file does not describe the fit. The file states only that the slipper has been tried on every reader, one by one, at this exact line, and has fit precisely those who checked just now whether it might. The wedding is in appendix D. You are invited. You have been initialing the guest list all along.",)
